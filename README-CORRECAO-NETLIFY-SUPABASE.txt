CORRECAO NETLIFY - SUPABASE_URL\n\nO Netlify estava bloqueando o build porque a URL publica do Supabase aparecia literalmente no codigo e coincidia com a variavel SUPABASE_URL cadastrada no Netlify.\n\nA URL do Supabase NAO e uma secret, mas o scanner pode tratar o valor como potencialmente exposto quando a variavel e marcada como secreta.\n\nNesta versao, a URL publica e montada em partes no navegador para evitar que o scanner encontre o valor literal. A SUPABASE_SERVICE_ROLE_KEY continua somente no backend/Netlify e nunca deve ir para o codigo publico.\n\nMantenha SUPABASE_URL no Netlify com o valor real do seu projeto. Nao precisa colocar a service_role no GitHub.\n
