FOTOS ULTRA QUALIDADE — RELPPS

O site agora NÃO reduz mais imagens pequenas para o tamanho nativo.
Na página do produto a foto ocupa praticamente toda a galeria.

Além disso, para cada imagem vinda por URL, o site tenta automaticamente variantes
sem parâmetros de thumbnail/resize e variantes comuns de URL original. Entre todas
as que carregarem, escolhe a de maior resolução.

IMPORTANTE: se a única imagem cadastrada no Bling for realmente um arquivo de 70x70
pixels, nenhum CSS ou código consegue criar detalhes que não existem no arquivo.
Nesse caso o site continuará mostrando grande, mas a solução de qualidade real é
cadastrar no Bling a foto original (recomendado 1000px ou mais). O Bling aceita
JPG/JPEG/PNG/WEBP de até 3 MB por imagem.
