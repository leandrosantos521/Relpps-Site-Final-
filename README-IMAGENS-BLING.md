# Imagens dos produtos: somente Bling

As imagens locais de produtos foram removidas deste pacote.

O site agora:
1. usa a imagem cadastrada no Bling quando disponível;
2. atualiza as imagens da página pelo endpoint de imagens do Bling quando a integração está ativa;
3. usa apenas um placeholder gerado pelo próprio JavaScript quando o produto ainda não possui imagem no Bling.

Logo, banners e imagens institucionais da identidade da Relpps continuam no pacote porque não são fotos de produtos.
